ELDROS — Content Display Portal (Display) Prototype

Minimal single-file frontend. Talks to CDP backend on http://localhost:7002. Access is IP-restricted (default allows localhost).

1) Terminal Context (Library Location)

Concurrency rule is enforced per contentId + locationId. Try opening this page in two browser windows with the same locationId and viewing the same item to see turnaway.

2) Search

This prototype searches in-memory metadata (real system uses Elasticsearch/Solr).

3) View Content (Concurrency + Turnaway)

No active viewing session.

Real CDP would stream PDFs via PDF.js and ePubs via epub.js using signed URLs. Here we display placeholder text.

4) Analytics (dev)

Counts search/view/turnaway events captured by backend.
