# Requirements Index — split by portal (PSP vs CDP)

This repository’s requirements describe **two separate portals**:

- **Deposit (Publishers)** = **Publisher Submissions Portal (PSP)** — where publishers register and submit content
- **Display (Readers)** = **Content Display Portal (CDP)** — where readers view content from library terminals (IP-restricted)

To make that split explicit, use the branch folders below.

## Deposit (PSP) requirements

See:

- `requitrements/deposit/README.md`
