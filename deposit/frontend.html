ELDROS — Publisher Submissions Portal (Deposit) Prototype

Minimal single-file frontend. Talks to PSP backend on http://localhost:7001. Demo staff user: staff@bl.uk

1) Registration Request (Guest)

Staff will approve/reject this request. If approved, the backend returns a temp password + an MFA secret for the publisher user (prototype convenience).

2) Login (Publisher / Staff) with MFA

Prototype behavior: after login step 1, backend returns demoTotpNow to help you proceed.

3) Publisher Submission (Upload metadata + file)

Duplicate/versioning: submit again with the same ISBN to create a new version. Trusted publishers auto-approve.

4) Staff Review

5) My submissions

Requires login.
